# Pruebas

La suite del nuevo LMS crecerá por capas:

1. autenticación y seguridad LTI;
2. aislamiento entre cursos y profesores;
3. motor SCORM;
4. persistencia de intentos/evidencias;
5. evaluación;
6. AGS/NRPS/Deep Linking;
7. regresión GTH.

No se considerará completada la migración de GTH hasta que las pruebas cubran los comportamientos funcionales de la aplicación estable de `CFGSAF/grh0652`.
