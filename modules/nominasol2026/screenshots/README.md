Este directorio está reservado exclusivamente a **capturas reales de TeamSystem NOMINASOL 2026 (Versión Educativa)**.

No se deben introducir maquetas, imágenes generadas ni recreaciones de la interfaz. El objetivo pedagógico es que el alumno vea exactamente la pantalla que encontrará al abrir el programa.
